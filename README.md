# احصائيات مقترح الترقيات لسنة 2026

لوحة لجنة شؤون أعضاء السلك الدبلوماسي والقنصلي لمقترح الترقيات لسنة 2026.

النسخة الداخلية: http://10.21.70.13/promotion-dashboard/

## التشغيل

```bash
npm install
npm run dev
```

تحديث البيانات من ملف Excel:

```bash
npm run import
npm run build
```

ضع الملف `src/data/DSO_Data.xlsx` محلياً قبل الاستيراد. هذا الملف غير مرفوع إلى GitHub.
